# Sesión 2: Pronósticos con Modelos Tradicionales

## Descripción
Esta sesión aborda modelos tradicionales para pronósticos de series temporales como ARIMA, SARIMA, y métodos de suavización exponencial.

## Estructura
- **clases/**: Notebooks con contenido teórico y ejemplos de clase
- **desarrollo/**: Notebooks con ejercicios y proyectos de desarrollo

## Temas
- Modelos autorregresivos (AR)
- Modelos de media móvil (MA)
- Modelos ARIMA y SARIMA
- Suavización exponencial
- Evaluación de pronósticos

## Subtemas
2.1. **Análisis de Residuales**
   - Diagnóstico de residuales del modelo
   - Pruebas de normalidad
   - Detección de autocorrelación en residuales

2.2. **Comportamiento de los Residuales**
   - Análisis visual de residuales
   - Patrones en residuales
   - Homogeneidad de varianza

2.3. **Componente Estacional**
   - Identificación de estacionalidad
   - Descomposición estacional
   - Parámetros estacionales en SARIMA

2.4. **Detalle Matemático del Modelo SARIMA**
   - Formulación matemática completa
   - Parámetros (p,d,q)(P,D,Q)m
   - Estimación de parámetros

2.5. **Pronóstico con el Modelo**
   - Generación de pronósticos
   - Intervalos de confianza
   - Evaluación de precisión del pronóstico
