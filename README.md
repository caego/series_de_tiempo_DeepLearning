# Series de Tiempo con Deep Learning
Conceptos fundamentales hasta la implementación de modelos avanzados para el análisis y predicción de series temporales.

## Estructura del Curso

Este repositorio contiene notebooks organizados en 6 sesiones:

### Sesión 1: Fundamentos de Series de Tiempo
Conceptos fundamentales, componentes temporales, estacionariedad y análisis exploratorio.
📁 [Sesion_01_Fundamentos_Series_Tiempo](Sesion_01_Fundamentos_Series_Tiempo/)

### Sesión 2: Pronósticos con Modelos Tradicionales
Modelos ARIMA, SARIMA y métodos de suavización exponencial.
📁 [Sesion_02_Pronosticos_Modelos_Tradicionales](Sesion_02_Pronosticos_Modelos_Tradicionales/)

### Sesión 3: MLP para Series de Tiempo
Introducción a redes neuronales Perceptrón Multicapa para series temporales.
📁 [Sesion_03_MLP_Series_Tiempo](Sesion_03_MLP_Series_Tiempo/)

### Sesión 4: Modelar una Serie de Tiempo con MLP
Implementación práctica y optimización de modelos MLP.
📁 [Sesion_04_Modelar_Serie_Tiempo_MLP](Sesion_04_Modelar_Serie_Tiempo_MLP/)

### Sesión 5: Estructuras de Redes Profundas para Series de Tiempo Univariadas
RNN, LSTM, GRU y arquitecturas profundas especializadas.
📁 [Sesion_05_Redes_Profundas_Series_Univariadas](Sesion_05_Redes_Profundas_Series_Univariadas/)

### Sesión 6: Redes Convolucionales para Series de Tiempo
CNN 1D, arquitecturas híbridas y modelos avanzados.
📁 [Sesion_06_Redes_Convolucionales_Series_Tiempo](Sesion_06_Redes_Convolucionales_Series_Tiempo/)

## Organización de Carpetas

Cada sesión contiene dos subcarpetas:
- **clases/**: Notebooks con contenido teórico y ejemplos de clase
- **desarrollo/**: Notebooks con ejercicios prácticos y proyectos de desarrollo
