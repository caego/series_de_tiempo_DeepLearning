# Sesión 4: Modelar una Serie de Tiempo con MLP

## Descripción
Esta sesión se enfoca en la implementación práctica de modelos MLP para series temporales, incluyendo técnicas de optimización y ajuste.

## Estructura
- **clases/**: Notebooks con contenido teórico y ejemplos de clase
- **desarrollo/**: Notebooks con ejercicios y proyectos de desarrollo

## Temas
- Diseño de arquitecturas MLP
- Hiperparámetros y optimización
- Regularización y prevención de overfitting
- Casos de estudio prácticos
- Comparación con modelos tradicionales
