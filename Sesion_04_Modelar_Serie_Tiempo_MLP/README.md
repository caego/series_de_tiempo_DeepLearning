# Sesión 4: Modelar una Serie de Tiempo con MLP

## Descripción
Esta sesión se enfoca en la implementación práctica de modelos MLP para series temporales, incluyendo técnicas de optimización y ajuste.

## Estructura
- **clases/**: Notebooks con contenido teórico y ejemplos de clase
- **desarrollo/**: Notebooks con ejercicios y proyectos de desarrollo

## Temas
- Diseño de arquitecturas MLP
- Hiperparámetros y optimización
- Regularización y prevención de overfitting
- Casos de estudio prácticos
- Comparación con modelos tradicionales

## Subtemas
4.1. **Preprocesamiento**
   - Normalización y escalado de datos
   - Creación de ventanas temporales
   - División de conjuntos de entrenamiento, validación y test
   - Tratamiento de valores faltantes

4.2. **Construcción del Modelo MLP**
   - Diseño de la arquitectura de capas
   - Selección de funciones de activación
   - Configuración de la capa de salida
   - Compilación del modelo

4.3. **Optimización de Hiperparámetros**
   - Búsqueda de hiperparámetros óptimos
   - Técnicas de validación cruzada
   - Ajuste de learning rate
   - Número de capas y neuronas por capa
