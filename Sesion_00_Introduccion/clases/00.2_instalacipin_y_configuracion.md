# Instalación y configuración

## Requisitos del sistema
- **Python 3.8 o superior**
- **pip**(gestor de paquetes de Python)
- **Github**

## Instalación del entorno

*Abre la terminal integrada en Visual Studio Code (Ctrl + `) o usa la terminal de tu sistema.*

**Nota:** Los comandos pueden usar `python3`, `python` o `py` según tu sistema operativo y configuración. Prueba cuál funciona en tu máquina.

### Linux/Mac:
1. Crear ambiente virtual
```bash
python3 -m venv .venv
```

2. Activar ambiente virtual
```bash
source .venv/bin/activate
```

3. Instalar dependencias
```bash
pip install -r requirements.txt
```

### Windows (CMD):
1. Crear ambiente virtual
```cmd
python -m venv .venv
```

2. Activar ambiente virtual
```cmd
.venv\Scripts\activate.bat
```

3. Instalar dependencias
```cmd
pip install -r requirements.txt
```

## Dependencias (para que sirven)
- **numpy:** operaciones numericas y arreglos.
- **pandas:** manejo de datos tabulares.
- **matplotlib:** graficas base.
- **seaborn:** visualizacion estadistica.
- **scikit-learn:** ML clasico y utilidades.
- **plotly:** graficas interactivas.
- **statsmodels:** modelos estadisticos y analisis.
- **tensorflow:** deep learning.
- **keras:** API de alto nivel para redes neuronales.
- **sktime:** herramientas para series de tiempo.
- **tsfresh:** extraccion automatica de caracteristicas.
- **bokeh:** visualizacion interactiva.
- **jupyter:** notebooks.
- **ipywidgets:** widgets interactivos en notebooks.
